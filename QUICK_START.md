# 🚀 Быстрый запуск ShelfLife

## Что это?
**ShelfLife** - мобильное приложение для контроля сроков годности продуктов с использованием API Open Food Facts.

## ⚡ Быстрый старт (5 минут)

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск Metro bundler
```bash
npm start
```

### 3. Запуск на Android (в новом терминале)
```bash
npm run android
```

## 📱 Основные функции

### ✅ Добавление продуктов
- **Сканирование штрих-кода** - нажмите на иконку сканера
- **Ручной ввод** - введите штрих-код или название продукта
- **Автозаполнение** - данные загружаются из Open Food Facts

### ✅ Управление продуктами
- **Просмотр списка** - все продукты с цветовой индикацией
- **Фильтрация** - по статусу (просроченные, скоро истекают, свежие)
- **Редактирование** - изменение данных и сроков

### ✅ Уведомления
- **Напоминания** - о приближающихся сроках истечения
- **Настройки** - количество дней до уведомления
- **Автоматическое планирование** - уведомления создаются автоматически

## 🎯 Тестирование

### Добавьте тестовый продукт:
1. Нажмите **"Добавить продукт"**
2. Нажмите на иконку **сканера** (📷)
3. Выберите тестовый штрих-код: **`3017620422003`** (Nutella)
4. Установите дату истечения срока
5. Сохраните

### Проверьте функции:
- ✅ Просмотр на главном экране
- ✅ Редактирование продукта
- ✅ Фильтрация в списке
- ✅ Настройки уведомлений

## 🛠 Технологии

- **React Native** - кроссплатформенная разработка
- **TypeScript** - типизированный код
- **Open Food Facts API** - база данных продуктов
- **AsyncStorage** - локальное хранение
- **Push Notifications** - уведомления

## 🔧 Возможные проблемы

### "SDK location not found"
**Решение:** Установите Android Studio и настройте ANDROID_HOME

### "Device not found"
**Решение:** Запустите эмулятор Android в Android Studio

### "Build failed"
**Решение:** Очистите кэш:
```bash
cd android && gradlew clean && cd .. && npm run android
```
