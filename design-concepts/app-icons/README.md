# App Icon Concepts

Refined final candidates:

- `icon-apelfresh-citrus.svg`: bright citrus-led direction for `ApelFresh`
- `icon-apel-monogram.svg`: cleaner brand-first direction that can flex to different `Apel*` names
- `icon-apel-hybrid-core.svg`: strongest merge of citrus fruit and monogram
- `icon-apel-hybrid-ring.svg`: premium dark icon with citrus ring around the mark
- `icon-apel-hybrid-badge.svg`: bold badge style with `AF` plus central monogram
- `icon-apel-hybrid-minimal.svg`: cleaner app-store friendly hybrid

These are concept files meant for review and iteration before exporting final PNG app assets.
