# Политика конфиденциальности ApelKeep

Дата обновления: 6 апреля 2026 года

## 1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные обрабатывает приложение ApelKeep, для каких целей они используются и как пользователь может управлять этими данными.

Используя приложение, пользователь соглашается с положениями настоящей Политики конфиденциальности.

## 2. Какие данные обрабатывает приложение

Приложение ApelKeep обрабатывает только данные, необходимые для его работы:

- список продуктов, добавленных пользователем;
- даты изготовления и срока годности продуктов;
- выбранные категории, количество, названия и изображения продуктов;
- локальный кэш рецептов и результатов проверки товаров;
- технические данные, необходимые для работы локальных уведомлений.

Приложение не требует регистрации и не собирает имя, адрес электронной почты, номер телефона, паспортные данные или иные сведения, позволяющие напрямую идентифицировать пользователя.

## 3. Где хранятся данные

Основные пользовательские данные хранятся локально на устройстве пользователя в памяти приложения.

Это означает, что:

- данные одного пользователя не отображаются другим пользователям;
- содержимое холодильника привязано к конкретному устройству;
- при удалении приложения или очистке его данных локальная информация может быть удалена с устройства.

## 4. Для чего используются сетевые запросы

Приложение может выполнять сетевые запросы только для работы отдельных функций:

- поиск информации о товаре по штрихкоду;
- получение рецептов;
- переход по ссылке на Telegram-канал по инициативе пользователя.

Приложение не использует сетевые запросы для передачи пользовательского холодильника другим пользователям.

## 5. Разрешения устройства

Приложение может запрашивать следующие разрешения:

- `Камера` — для сканирования штрихкодов и дат на упаковке;
- `Уведомления` — для напоминаний о приближении срока годности;
- `Вибрация` и системные механизмы Android для уведомлений — для корректной доставки напоминаний;
- системные механизмы планирования напоминаний Android — для показа уведомлений в нужное время.

Разрешения используются только для функций приложения и не применяются для скрытого сбора персональных данных.

## 6. Передача данных третьим лицам

ApelKeep не продаёт и не передаёт персональные данные пользователей третьим лицам.

При использовании функций поиска товара и рецептов приложение может обращаться к внешним API, необходимым для получения информации о товарах и рецептах. Такие обращения носят технический характер и используются только для работы соответствующих функций.

## 7. Защита данных

Мы принимаем разумные технические меры для защиты данных, доступных приложению, включая хранение основной пользовательской информации локально на устройстве и ограничение перечня запрашиваемых разрешений.

## 8. Удаление данных

Пользователь может удалить данные приложения следующими способами:

- удалить отдельные продукты внутри приложения;
- очистить данные приложения в настройках Android;
- удалить приложение с устройства.

## 9. Изменение политики

Настоящая Политика конфиденциальности может обновляться. Актуальная версия должна быть опубликована по той ссылке, которая указана в карточке приложения.
